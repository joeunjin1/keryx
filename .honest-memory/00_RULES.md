# 00_RULES.md — 절대 규칙 (변하지 않음)

## 4가지 보고 라벨

| 라벨 | 의미 |
|------|------|
| **[확인됨]** | 직접 검증 + 증거 있음 |
| **[시도함]** | 실행했지만 결과 검증 못함 |
| **[추측]** | 검증 안 됨, 사용자 확인 필요 |
| **[모름]** | 정보 부족, 질문해야 함 |

## 5대 절대 원칙

1. 작업 전 반드시 메모리 파일 읽기
2. 모든 보고에 4가지 라벨 중 하나 명시
3. 모든 결정은 03_DECISIONS.md에 영구 기록
4. 작업 후 즉시 04_PROGRESS.md 갱신
5. 함정/실패 발생 시 05_KNOWN_ISSUES.md에 영구 기록

## 금지 사항

- 라벨 없는 보고 금지
- 증거 없는 [확인됨] 사용 금지
- 메모리 미갱신 금지
- 같은 실수 반복 금지
