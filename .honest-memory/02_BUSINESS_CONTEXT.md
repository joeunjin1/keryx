## 주력 사업

- 중국 → 한국 무역 (B2B)
- 뽑기용 굿즈 상품, 인형, 가방고리
- 부직포 보냉백 (가자트레이드)
- 자체 IP 개발: 뿌찌프랜즈, 덕클, 디노몬
- 글로벌 수출 계획 (알리바바 + 자체 사이트)

## KERYX 플랫폼 목적

중국 공장 ↔ 한국 바이어 B2B 매칭 플랫폼
- 시장조사 → 샘플개발 → 공장매칭 → 검수 → 물류 전 파이프라인
- MD가 공장과 바이어 사이에서 코디네이터 역할

## 사용자 역할 구조

| 역할 | 설명 |
|------|------|
| 관리자 (admin) | 최고 권한, 최종 승인 |
| MD | 공장/바이어 코디네이터, 1차 승인 |
| 셀러 (seller) | 한국 바이어 |
| 공장 (factory) | 중국 공급업체 |

## 언어 지원

- 한국어 (기본)
- 중국어 (/zh 경로)

## 핵심 워크플로우

1. 공장이 상품 등록 (approval_status: pending_review)
2. MD가 검토/수정 후 1차 승인 (md_approved)
3. 관리자가 최종 승인 (approved) → /shop 자동 노출
4. 셀러가 카탈로그에서 주문
5. 주문 → 생산 → 검수 → 운송 → 청구서
